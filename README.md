# RetroRadar

Windows-native Rust mission-control display based on [mctl by Liam Droog](https://github.com/LiamDroog/mctl).
Independent repository; no GitHub fork. GPL-3.0-or-later; original credits preserved.

The initial implementation is on [agent/r01-windows-foundation](https://github.com/TheWinterLynx/retroradar/tree/agent/r01-windows-foundation), pending the owner's local Windows gate.
main currently contains the project contract and provenance only.

See [AGENTS.md](AGENTS.md) for the branch/local-gate workflow and [provenance](docs/UPSTREAM.md).
